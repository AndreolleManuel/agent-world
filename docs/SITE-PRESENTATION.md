# Présentation proposée pour le site

## Agent World

Vos agents Hermes prennent place dans un laboratoire pixel-art. Voyez lesquels travaillent, attendent une décision ou n'envoient plus de preuve d'activité, depuis votre Mac.

Gratuit et open source. Conçu pour les développeurs qui utilisent déjà Hermes et souhaitent garder leurs données chez eux. L'application observe les états ; elle ne commande pas les agents.

**Bouton : Voir le code et l'installation sur GitHub**

Destination : `https://github.com/AndreolleManuel/agent-world` après publication de la version examinée. Présenter 0.2.0 comme candidat/bêta tant que les conditions de distribution stable ne sont pas satisfaites. Éviter un lien direct vers les anciennes archives 0.1.x.

Précisions visibles : Mac ; mode local ou VPS préparé par un administrateur ; aucune télémétrie AM Labs ; clé SSH de consultation dédiée ; bêta Mac non notarisée le cas échéant. Lien vers confidentialité, licence et limites testées.

Pour le Reel : utiliser les données démo et le marquage « Mode démo ». Ne montrer ni noms privés, titres réels, hôte, terminal de secrets ou chemin de clé. Une capture de fonctionnement suffit ; aucune promesse « 100 % sécurisé » ou « accessible uniquement aux développeurs ».

Texte prêt à intégrer ; aucune modification ni publication du site effectuée par ce document.
